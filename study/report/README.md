# `study/report/` — JSON study artifacts

Machine-readable examples and summaries used for papers, debugging, and handoffs.

Parent: [`../README.md`](../README.md) · Human HTML reports: [`../reports/`](../reports/README.md).

---

## Typical contents

| File | Purpose |
|---|---|
| `study_pipeline.json` | Pipeline description / metadata |
| `hypotheses.json` | Contrast hypotheses (H1–H5) artifacts |
| `metrics_schema.json` | Metric schema documentation |
| `results_summary.json` | Aggregated results snapshot |
| `rules_checked.json` | Rule validation outcomes |
| `example_profile.json` / `example_pathways.json` | Illustrative examples |

Prefer regenerating from scripts over hand-editing when possible.
